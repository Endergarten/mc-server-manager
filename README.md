# MC Server Manager

一个以 **开服** 为核心的轻量 Minecraft 服务端管理器。Go 编写，网页界面内嵌在程序中，无第三方 Go 依赖，无需 Python、Node.js、Docker 或数据库。

第一版面向 Windows 本机管理，支持原版 Java 服务端。一个地图存档对应一个独立开服实例，可使用不同的 Minecraft 版本。

## 已实现

- 服务器卡片：名称、地图封面、简介、游戏版本和运行状态；支持搜索、编辑和自定义封面。
- 拖拽导入地图 ZIP：自动定位 `level.dat`，支持多层目录、多存档选择，确认版本后导入。
- 版本识别：优先读取 `mcversion.txt`，其次读取 `level.dat` 中最后保存的版本；始终允许人工确认修改。
- 官方服务端版本库：从 Mojang 获取版本列表，区分正式版、快照、预发布版、候选版。
- 下载进度、大小及 SHA-1 校验；下载完后读取 JAR 内部版本，再安装到本地版本库。
- 导入已有官方 `server.jar`，识别内部版本。现代 bundler JAR 与含 `version.json` 的 JAR 均可识别。
- 缺少服务端时，“下载并启动”会下载对应版本，成功后启动实例。
- 实时后台、命令输入、正常 `stop` 保存关服；退出管理器时先等待服务端停止，不会自动强制杀进程。
- 可配置管理员列表（每行一个游戏名），开服时自动同步 OP；全新安装默认留空，不内置个人账号。关闭正版验证及白名单，开启命令方块和允许飞行。
- 地图独立保存游玩进度，停止状态可备份完整实例 ZIP。
- 管理页面只监听 `127.0.0.1`，校验 Host、Origin 和写操作令牌；无远程管理登录功能。
- ZIP 解压检查路径越界、符号链接、重复路径、Windows 保留名称和解压大小。

## 使用

1. 将 Windows 版本的 `mc-server-manager.exe` 放入一个可写目录，例如 `D:\mc\manager`，双击启动。
2. 浏览器会自动打开 `http://127.0.0.1:18180`。不要同时运行多个管理器。
3. 到“开服设置”确认 Java 路径、内存、端口及管理员；阅读并同意 [Minecraft EULA](https://www.minecraft.net/eula) 后保存。
4. 拖入地图 ZIP，确认名称、简介和需要的 Minecraft 版本。
5. 点击“下载并启动”，或先在“服务端版本”里导入已有 JAR，再点击“启动服务器”。
6. 到“服务器后台”查看日志和发送命令。关服使用“保存并停止”，退出使用左下角“退出管理器”。

本机游戏连接 `localhost:25565`；如修改了服务器端口，请使用相应端口。网页管理端口 `18180` 与游戏端口是两回事。关闭浏览器页面不会关服。

Java 仍然需要单独提供。程序优先寻找 Minecraft 自带的 `java-runtime-epsilon`，再检查 `JAVA_HOME`、`PATH`。所选 Java 必须兼容所运行的 Minecraft 版本。第一版使用全局 Java 路径，切换旧版服务端前可在设置中修改。

管理员列表可添加多个游戏名，启动时以配置列表为准重写实例 `ops.json`，原内容保留为 `ops.before-manager.json`。列表中删除的账号下次启动不再拥有 OP；运行期间可通过后台 `op` / `deop` 命令临时调整。旧配置中的单个管理员会自动迁移到新列表。

允许飞行只关闭服务端的飞行踢出检查，不会自动赋予玩家飞行能力。离线模式不验证玩家身份，仅应将游戏连接开放给信任的玩家。

## 构建与测试

需要 Go 1.22 或更高版本：

```sh
go test ./...
go vet ./...
go build -trimpath -o dist/mc-server-manager.exe .
```

Windows 可直接运行项目中的 `build.bat`。开发运行：

```sh
go run . --data ./data --no-browser
```

默认数据目录为可执行程序旁的 `data`。`go run` 时请显式指定 `--data`，避免将数据放在临时编译目录。可用参数：

```text
--data D:\mc\manager\data    数据目录
--port 18180                 管理页面端口
--no-browser                 不自动打开浏览器
```

## 数据目录

```text
data/
  library.json               实例说明和开服设置
  servers/<version>/         共用的官方 server.jar 和下载元信息
  instances/<id>/
    world/                   实际地图存档，游玩进度保存在这里
    server.properties        开服配置
    ops.json                 管理员
    manager-console.log      持久化后台日志
    cover                    自定义封面（可选）
  backups/                   实例备份 ZIP
  staging/                   导入和下载临时文件
```

程序不会将地图、服务端 JAR、配置、日志或私钥提交到仓库。迁移本机数据时，正常停止后复制整个 `data` 目录即可。备份 ZIP 当前通过手动解压恢复；界面中的一键恢复尚未实现。

## 第一版边界与后续方向

- 同时运行一个实例；切换地图先正常关服，避免端口冲突。
- ZIP 上传最大 2 GB、解压后最大 8 GB、最多 100000 个条目；地图必须是 Java 版存档。
- 自动识别的存档版本不保证等于作者最低要求，请在导入对话框确认。
- 支持原版官方 JAR；部分非常旧的服务端可能没有可识别的内置版本信息，暂不支持导入。
- 官方下载失败可重试，或手动导入 JAR；当前不提供第三方镜像、断点续传、自动安装 Java。
- 退出前请使用网页退出按钮或控制台 Ctrl+C；不要在运行服务器时强制结束管理器。
- 这是本机个人管理工具，不包含公网面板、多用户权限或远程开服能力。
